# Call Sound Assets

Đặt các file âm thanh sau vào thư mục này:

- `ringtone.mp3` — Chuông reo khi có cuộc gọi đến (incoming call, callee)
- `ringback.mp3` — Tone chờ khi đang gọi đi (outgoing call, caller)

Nếu các file này không có, app sẽ chỉ rung (vibration) mà không có âm thanh.

## Nguồn âm thanh miễn phí

- https://freesound.org — tìm "phone ringtone", "ringback tone"
- https://mixkit.co/free-sound-effects/phone/
- iOS/Android system sounds (cần kiểm tra license)
